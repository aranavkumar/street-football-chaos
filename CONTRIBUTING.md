# Contributing to Street Football Chaos

Thank you for your interest in contributing to **Street Football Chaos**!

## How to Contribute

1. **Fork the Repository:** Create your own fork by clicking the Fork button on GitHub.
2. **Clone the Fork:**
   ```bash
   git clone https://github.com/<your-username>/street-football-chaos.git
   cd street-football-chaos
   ```
3. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make Your Changes:** Test your modifications locally to ensure everything works smoothly.
5. **Commit Your Changes:**
   ```bash
   git commit -m "Add descriptive commit message"
   ```
6. **Push to Your Branch:**
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Submit a Pull Request:** Open a pull request against the `main` branch with details on what you changed and why.

## Code Guidelines
- Keep CSS clean, modern, and responsive across various screen resolutions.
- Ensure all interactive controls and embedded game frames remain fully accessible.
- Maintain consistent indentation and structure in HTML/JS.
