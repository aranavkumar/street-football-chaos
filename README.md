## 🎮 Overview

**Street Football Chaos** is a high-octane 2v2 street football game with zero referee intervention. No fouls, no cards, and no offsides. If you want the ball back, you tackle the carrier with punches, slide dropkicks, or send them flying into the fence. 

Playable directly in your browser with full keyboard and gamepad support.

---

## 🕹️ Controls

| Action | Keyboard | Gamepad |
| :--- | :--- | :--- |
| **Move** | `Arrow Keys` | `D-Pad / Left Stick` |
| **Sprint** | `E` (hold) | `Right Trigger / R2` |
| **Quick Pass** | `S` | `A / Cross` |
| **Through Ball** | `W` | `Y / Triangle` |
| **Lob Pass / Dropkick** *(defending)* | `A` | `X / Square` |
| **Shoot / Punch** *(defending)* | `D` (hold to charge) | `B / Circle` |
| **Skill Move / Dash** | `Z` | `Left Bumper / L1` |
| **Ultimate** *(when meter full)* | `X` | `Right Bumper / R1` |
| **Core Upgrade Pick** | `1`, `2`, `3` | `D-Pad Left / Up / Right` |
| **Pause** | `Esc` | `Start / Options` |

> 💡 **Tip:** Click inside the game window once to ensure it captures all keyboard and gamepad inputs.

## ✨ Features

- 🥊 **Combat-Driven Tackles:** Knock balls loose by delivering straight punches or launching dropkicks.
- ⚡ **Dynamic Arcade Gameplay:** Smooth physics, charged strikes, and skill dashes for high-speed counterattacks.
- 💥 **Ultimate Abilities:** Build your energy meter during match brawls to unleash devastating power shots.
- 🎮 **Plug-and-Play Controller Support:** Native gamepad mapping out of the box.
- 🌐 **Cross-Platform Browser Delivery:** Zero installation required—runs cleanly on any modern desktop browser.

## 🛠️ Local Development

To run or modify the website locally on your computer:

```bash
# 1. Clone the repository
git clone https://github.com/aranavkumar/street-football-chaos.git

# 2. Navigate into the project directory
cd street-football-chaos

# 3. Open index.html directly in your preferred browser
open index.html

# Alternatively, run a lightweight local static server:
npx serve .
```
